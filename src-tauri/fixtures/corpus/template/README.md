# 官方范本「合法雷同」误报语料（template false-positive corpus）

多份标书照抄同一份**官方招标文件范本**是合法且普遍的：范本由国家机关发布、全国强制或
推荐适用，投标人逐字引用其条款不构成任何串标嫌疑。但对交叉查重而言，这些段落**文本上
就是雷同的**——它们是本工具最主要的误报来源。

本目录的语料专门量化这一风险：**全部为负样本**（合法共享 ≠ 串标），用单边误报率探针
（`engine::extcalib::false_positive_probe`）评估「多大比例的合法样板会在默认阈值被标记」，
而不是套用 ROC/PR-AUC——没有正类时两侧判别指标无定义，会把「无正类」误读成「判别失败」。

配套测试：`corpusgen::tests::template_fp_probe`（误报率 + 分数分布，对照
`../baseline_metrics_template_fp.json`）与
`corpusgen::tests::official_template_not_covered_by_builtin_library`（成因固化，见下）。

## 格式

复用 `engine::extcalib::ExternalPair`，每行一条；`label` 恒为 `0.0`（不构成串标证据），
`subclass` 标注重叠强度分档：

| subclass | 构造 | 含义 |
| --- | --- | --- |
| `verbatim` | 两侧为**同一条**范本条款 | 两份标书逐字照抄同一样板的极限情形 |
| `sibling` | **同章不同条款** | 内容不同但共享法务/招投标语域，测词汇重叠导致的误报 |
| `cross_chapter` | **跨章条款** | 重叠更弱的对照组 |

**零合成变换**：全部文本直接取自范本原文，未施加任何改写——避免重蹈合成生成器
「变换器与检测器同源」的循环（见 `corpusgen` §8 风险①）。

## 数据集来源与许可

### ndrc2007-template.jsonl
- **来源**：《中华人民共和国标准施工招标文件》（2007 年版），国家发展改革委等九部委
  第 56 号令发布，全国依法必须招标的工程施工项目适用。
  原文（官网直链 DOC，免注册）：
  https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/200712/t20071221_960708.html
- **抽取**：官方 DOC（1,415,680 字节，Word 元数据自述 13851 词 / 78952 字符）经
  `textutil` 转 UTF-8；按条款号（`1.1.1` / `2.3` 形式）切分为 chunk 量级单元，保留
  120–900 字、汉字密度 > 55% 的正文条款，覆盖招标公告 / 投标人须知 / 评标办法（两法）/
  合同条款 / 工程量清单，共 112 个单元 → 132 对。
- **许可**：国家机关以部委令发布的规范性文件，依《中华人民共和国著作权法》第五条
  「法律、法规，国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件」不适用
  著作权法，可自由复制传播。收录时以「发改委等九部委 第56号令 + 官网 URL」声明来源。
- **脱敏**：范本正文为占位符形式（`（项目名称）`、`见投标人须知前附表`），不含任何真实
  主体名 / 项目名 / 金额 / 人名 / 联系方式，无需脱敏。

## 已测得的结论（词面档，阈值 0.7）

| subclass | n | FPR | mean | max |
| --- | --- | --- | --- | --- |
| verbatim | 40 | **1.000** | 1.000 | 1.000 |
| sibling | 51 | 0.000 | 0.165 | 0.643 |
| cross_chapter | 41 | 0.024 | 0.121 | 0.807 |

两条都值得记住：

1. **好消息**：`sibling` 误报率为 0——共享法务语域、术语高度重叠**并不会**造成误报。
   全语料 IDF 把样板高频词的权重压低了，词面维确实在挑「区分性词」，设计有效。
2. **坏消息且可执行**：`verbatim` 误报率 100%。生产虽有模板抑制路径
   （chunker 词频余弦 ≥ 0.7 命中 `source_templates` 即标 `is_template`，compare 侧按
   `ignore_templates` 在召回前剔除），但**内置模板库只有 3 条泛用短句**
   （法律法规引用 / 资质证书目录 / 标准售后承诺，`migrations::SEED_TEMPLATES_V2`）。
   实测这 132 条官方范本条款对内置库的**最高余弦仅 0.223**，命中 0 条——远够不着 0.7 阈值。
   即：官方标准条款目前不受任何抑制，逐字照抄必然满分误报。
   **应对**：把官方标准范本条款补入 `source_templates`（本语料即现成素材）。
